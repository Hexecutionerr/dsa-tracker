# Hasnain's DSA Tracker

A modern, personalized DSA Tracker built with React, Vite, Zustand and Tailwind CSS.

## Features

- Progress Tracking
- Topic & Subtopic Management
- Drag & Drop
- Search & Filters
- Notes
- Revision
- Analytics
- Dark Theme
- Responsive Design

## Tech Stack

- React
- Vite
- Tailwind CSS
- Zustand
- Lucide React
- @hello-pangea/dnd

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
